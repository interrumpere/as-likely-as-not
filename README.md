# As Likely As Not

A single-player narrative investigation set in Western New York in 1971, 2001 and 2003. Browser game: TypeScript, Vite, inkjs.

**Contains every spoiler.** The design lives in `design/BIBLE.md`, which is generated from Andre's canonical .docx in `design/source/`. Anyone working on the repo, human or agent, should read `AGENTS.md` first.

| Where | What |
|---|---|
| `AGENTS.md` | How the writing and coding agents share work |
| `design/` | The bible, decisions log, proposals, the shared ID contract (`STATE.md`), and the two inboxes |
| `content/` | Ink and data, all player-facing text |
| `src/`, `tests/` | Engine, rules and tests (bible §14.2) |
